## Customization Guide

### Change Company Branding
1. **Logo:** Replace `/assets/images/logo/logo-1.svg` and `logo-4.svg`
2. **Contact Info:** Update email and phone across all pages
3. **Company Name:** Search & replace "Cleva" in all HTML files
4. **Promotional Messages:** Edit `.rts-ht__promo` sections

### Update Pricing
1. Open `pricing.html` or `pricing-*.html`
2. Locate `rt-price` spans with dollar amounts
3. Update prices in currency elements
4. Modify feature lists in pricing cards

### Add New Pages
1. Copy existing HTML page as template
2. Update page title and meta tags
3. Customize content sections
4. Update navigation links
5. Test on mobile and desktop

### Customize Colors
1. Edit `/assets/css/style.css`
2. Find color variables (typically at top)
3. Update gradient colors for buttons, backgrounds
4. Test throughout all pages

### Troubleshooting 403 Errors
If you encounter "Access Forbidden" errors:

1. Check file permissions:
   ```bash
   chmod 755 /Applications/XAMPP/xamppfiles/htdocs/cleva-front/
   chmod 644 /Applications/XAMPP/xamppfiles/htdocs/cleva-front/*.html
   chmod -R 755 /Applications/XAMPP/xamppfiles/htdocs/cleva-front/assets/
   ```

2. Restart Apache:
   ```bash
   /Applications/XAMPP/xamppfiles/bin/apachectl restart
   ```

3. Verify Apache is running:
   ```bash
   ps aux | grep httpd
   ```
