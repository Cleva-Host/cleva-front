# Cleva Front - Landing Page Setup

## Overview
The cleva-front landing page has been created using the "index-two.html" template from the Hostie theme, customized for the Cleva brand with inspiration from whogohost.com's modern hosting provider design.

## Project Structure
```
cleva-front/
├── index.html          # Main landing page
├── assets/             # Static assets
│   ├── css/           # Stylesheets
│   ├── js/            # JavaScript files
│   └── images/        # Images and icons
├── README.md
└── SETUP.md           # This file
```
